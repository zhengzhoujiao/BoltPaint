# BoltPaint API 接口文档

本文档详细说明了 BoltPaint 后端提供的所有 API 接口、数据模型及核心业务流程。

---

## 1. 核心模块与端点

### 1.1 用户管理 (Users)
- `POST /user/register`: 用户注册（手机号 + 验证码 + 密码）。
- `POST /user/login`: 用户登录（用户名/手机号 + 密码）。
- `POST /user/send-code`: 发送手机验证码。
- `POST /user/verify-code`: 验证验证码。
- `GET /user/me`: 获取当前登录用户信息。
- `PUT /user/update`: 更新用户信息（头像、昵称、手机号）。

### 1.2 充值档位 (Recharge Packages)
- `GET /recharge-packages`: 充值档位列表（客户端仅展示 `enabled=true`）。
- `POST /recharge-packages` / `PUT /recharge-packages/{id}` / `DELETE /recharge-packages/{id}`: 管理端维护。

### 1.3 模板管理 (Templates)
- `GET /templates`: 获取模板列表（支持筛选：category, search, pagination）。
- `GET /templates/{template_id}`: 获取模板详情。
- `POST /templates`: 创建模板（管理员权限）。
- `PUT /templates/{template_id}`: 更新模板。
- `DELETE /templates/{template_id}`: 删除模板。
- `POST /templates/{template_id}/collect`: 收藏/取消收藏模板。
- `GET /templates/user/collections`: 获取当前用户收藏列表。

### 1.4 作品管理 (Artworks)
- `GET /artworks`: 获取作品广场列表（已发布的作品）。
- `GET /artworks/{artwork_id}`: 获取作品详情。
- `POST /artworks`: 保存作品配置。
- `PUT /artworks/{artwork_id}`: 更新作品信息（名称、发布状态）。
- `DELETE /artworks/{artwork_id}`: 删除作品。
- `POST /artworks/{artwork_id}/like`: 点赞/取消点赞作品。
- `GET /artworks/user/my`: 获取当前用户的作品列表。
- `GET /artworks/user/likes`: 获取当前用户点赞的作品。

### 1.5 图片生成 (Generate & Tasks)
- `POST /generate`: 发起生图请求（同步调用或异步任务触发）。
- `GET /tasks`: 获取生图任务列表（分页、状态筛选）。
- `GET /tasks/{task_id}`: 获取特定任务状态。
- `DELETE /tasks/{task_id}`: 删除任务记录。
- `GET /tasks/stats/summary`: 获取个人任务统计（总数、成功、失败）。

### 1.6 标签管理 (Tags)
- `GET /tags`: 获取所有标签（按 `order` 权重排序）。
- `POST /tags`: 创建新标签（管理员）。
- `GET /tags/{tag_id}`: 获取标签详情。
- `PUT /tags/{tag_id}`: 更新标签。
- `DELETE /tags/{tag_id}`: 删除标签。

### 1.7 系统运维 (Dashboard & Uploads)
- `GET /dashboard/stats`: 获取管理端概览数据（今日用户、收入、任务成功率、待处理工单）。
- `GET /dashboard/chart/user-growth`: 近7日用户增长趋势。
- `GET /dashboard/chart/order-flow`: 近7日订单流水数据。
- `POST /uploads/image`: 通用图片上传接口，返回可访问的静态 URL。

### 1.8 订单与工单 (Orders & Tickets)
- `POST /orders/alipay/pay`: BoltPaint 直连支付宝创建支付（body: `package_id`, `pay_type`；金额与豆子由服务端档位解析）。
- `POST /orders/alipay/notify`: 支付宝异步通知与幂等入账。
- `GET /orders/alipay/return`: 支付宝同步回跳。
- `GET /orders/{order_id}/alipay/query`: 主动查询支付宝订单状态。
- `POST /orders`: 创建支付订单。
- `GET /orders`: 获取历史订单。
- `POST /tickets`: 提交工单反馈。
- `GET /tickets`: 获取工单列表/详情。

## 2. 数据模型规范 (Data Models)

### 2.1 用户 (User)
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | string | 用户唯一标识 |
| `username` | string | 用户名 |
| `phone` | string | 绑定手机号 |
| `avatar` | string | 头像 URL |
| `balance_beans`| int | 账户余额 (豆子) |
| `is_admin` | bool | 是否具备管理员权限 |

### 2.2 模板 (Template)
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | string | 模板 ID |
| `name` | string | 模板标题 |
| `category` | string | 风格分类 (如: Cyberpunk, Oil Painting) |
| `price` | int | 单次生图消耗豆子数 |
| `preset_prompt`| string | 后台预设提示词 |
| `tags` | string[] | 关联的标签 ID 列表 |

### 2.3 作品 (Artwork)
| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | string | 作品唯一标识 |
| `image_url` | string | 图片存储路径/URL |
| `is_release` | bool | 是否发布到公共广场 |
| `likes_count` | int | 总获赞数 |
| `status` | string | 生成状态 (completed/failed) |

## 3. 核心业务逻辑说明

### 3.1 权限控制
- 目前大部分接口通过 `user_id` 参数模拟（默认 `u_001`）。
- **[TODO]** 后续将集成 JWT 认证，统一从 Request Header 中提取用户信息。

### 3.2 资源访问
- 生成或上传的图片统一存储在 `f:\BoltPaint\data\uploads` 中。
- 前端通过 `/static/{filename}` 路径访问映射后的静态资源。

### 3.3 图片生成超时处理
- 后端调用 Gemini 3 Pro API 设置了 **180s** 宽限期。
- 建议前端在调用 `/generate` 时实现相应的 Loading 状态或轮询 `/tasks`。
