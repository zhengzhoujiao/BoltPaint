# 支付宝H5支付集成指南

## 快速开始

### 1. 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

### 2. 配置支付宝凭证

#### 获取支付宝凭证

1. 访问 [支付宝开放平台](https://open.alipay.com/)
2. 登录并创建应用
3. 获取以下信息:
   - **APPID**: 应用ID
   - **应用私钥**: RSA2格式私钥
   - **支付宝公钥**: RSA2格式公钥

#### 配置环境变量

编辑 `backend/.env` 文件，添加以下配置:

```env
# 支付宝配置
ALIPAY_APP_ID=你的应用ID
ALIPAY_PRIVATE_KEY=你的应用私钥(去除头尾标记)
ALIPAY_PUBLIC_KEY=支付宝公钥(去除头尾标记)
ALIPAY_GATEWAY=https://openapi.alipaydev.com/gateway.do  # 沙箱环境
ALIPAY_RETURN_URL=http://localhost:5173/payment/result
ALIPAY_NOTIFY_URL=你的公网回调地址/orders/alipay/notify
```

> **注意**: 密钥需要去除 `-----BEGIN/END-----` 标记，只保留中间内容

支付相关环境变量均在 `backend/.env.example` 中，复制为 `.env` 后按需填写即可。

### 3. 启动服务

#### 后端服务

```bash
cd backend
python run.py
```

后端将运行在 `http://localhost:8000`

#### 前端服务

```bash
cd webApp
npm run dev
```

前端将运行在 `http://localhost:5173`

## 支付流程

### 用户支付流程

1. 用户在个人中心点击"充值"
2. 选择充值套餐和支付方式(支付宝)
3. 点击确认支付
4. 跳转到支付宝H5支付页面
5. 完成支付后返回结果页面
6. 系统自动查询支付状态并更新余额

### 技术流程

```
前端 -> 创建订单 -> 后端
前端 -> 请求支付URL -> 后端 -> 调用支付宝API -> 返回支付URL
前端 -> 跳转到支付宝H5页面
用户 -> 完成支付
支付宝 -> 异步通知 -> 后端 -> 更新订单状态和用户余额
前端 -> 轮询查询支付状态 -> 后端 -> 查询支付宝API
前端 -> 显示支付结果
```

## API接口

### 1. 创建支付

**POST** `/orders/alipay/pay`

使用登录态创建支付宝支付订单。请求体只提交充值档位和终端类型，金额与豆子由后端读取：

```json
{
  "package_id": "rp_starter",
  "pay_type": "h5"
}
```

**响应示例**:
```json
{
  "payment_url": "https://openapi.alipaydev.com/gateway.do?...",
  "order_id": "BP_1738123456789_ab12cd34"
}
```

### 2. 支付回调

**POST** `/orders/alipay/notify`

支付宝异步通知接口，接收支付结果。

**必须返回**: `"success"` 字符串表示接收成功

### 3. 查询支付状态

**GET** `/orders/{order_id}/alipay/query`

主动查询订单支付状态。

**响应示例**:
```json
{
  "order_id": "BP_1738123456789_ab12cd34",
  "status": "paid"
}
```

## 沙箱测试

### 使用沙箱环境

1. 配置沙箱网关:
   ```env
   ALIPAY_GATEWAY=https://openapi-sandbox.dl.alipaydev.com/gateway.do
   ```

2. 获取沙箱账号:
   - 访问 [沙箱应用](https://openhome.alipay.com/platform/appDaily.htm)
   - 查看买家账号信息

3. 测试支付:
   - 使用沙箱买家账号登录
   - 完成模拟支付(无需真实付款)

### 内网穿透(用于回调测试)

由于支付宝需要访问公网地址进行回调，本地开发需要使用内网穿透工具:

**使用 cpolar**:

```bash
cpolar http 8000
```

获得公网地址后，更新 `.env`:
```env
ALIPAY_NOTIFY_URL=https://your-ngrok-url.ngrok.io/orders/alipay/notify
```

## 生产部署

### 切换到生产环境

1. 更新网关地址:
   ```env
   ALIPAY_GATEWAY=https://openapi.alipay.com/gateway.do
   ```

2. 更新回调地址(必须是HTTPS):
   ```env
   ALIPAY_NOTIFY_URL=https://your-domain.com/orders/alipay/notify
   ALIPAY_RETURN_URL=https://your-domain.com/payment/result
   ```

3. 使用生产环境凭证

### 安全建议

- ✅ 使用HTTPS协议
- ✅ 妥善保管私钥，不要提交到代码仓库
- ✅ 验证所有支付回调的签名
- ✅ 实现订单幂等性处理
- ✅ 记录所有支付日志

## 常见问题

### Q: 签名验证失败?

**A**: 检查以下几点:
- 私钥和公钥格式是否正确(去除头尾标记)
- 是否使用了正确的密钥对
- 沙箱环境需使用沙箱密钥

### Q: 回调通知收不到?

**A**: 
- 确认 `ALIPAY_NOTIFY_URL` 是公网可访问的地址
- 本地开发使用内网穿透工具
- 检查防火墙设置

### Q: 支付后余额未更新?

**A**:
- 检查后端日志，确认收到回调通知
- 验证签名是否通过
- 检查订单状态是否正确更新
