# BoltPaint 数据库详细设计文档

本文档描述 BoltPaint 后端 **MongoDB** 的集合、字段与索引策略，并与 [`app/models.py`](../app/models.py) 及 [`database/init_db.py`](../database/init_db.py) 保持一致。

---

## 1. 数据库概览

| 项 | 说明 |
| :--- | :--- |
| 数据库类型 | MongoDB |
| 默认库名 | `bolt_painting`（可由 `.env` 配置） |
| 驱动 | `motor`（异步） |
| 索引创建 | 应用启动时 `init_database()` 内调用 `ensure_database_indexes()`（幂等） |

---

## 2. 集合一览

| 集合名 | 用途 |
| :--- | :--- |
| `users` | 用户、认证、余额、点赞/收藏列表 |
| `templates` | 生图模板与审核状态 |
| `artworks` | 已保存作品（含广场展示） |
| `tasks` | 异步生图任务状态 |
| `orders` | 充值订单 |
| `tickets` | 客服工单 |
| `tags` | 标签字典 |
| `pricing_strategies` | 计价策略（分辨率档位价格 + 绑定模型） |
| `image_models` | 可选生图模型配置 |
| `system_settings` | 键值系统配置 |
| `recharge_packages` | 充值档位 |
| `activation_codes` | 注册激活码 |
| `counters` | 自增计数器（如 `member_number`） |

---

## 3. 集合字段说明

### 3.1 `users`

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | string | 业务用户 ID（如 `u_xxx`） |
| `username` | string | 登录名，唯一 |
| `phone` | string? | 手机号（唯一语义字段；未绑定可为空） |
| `password_hash` | string | **Fernet 可逆加密**存储的密码（非 SHA-256；兼容旧 SHA256 文档的校验见代码） |
| `balance_beans` | int | 豆子余额 |
| `avatar` | string? | 头像 URL |
| `is_admin` | bool | 管理员 |
| `is_disabled` | bool | 是否禁用 |
| `is_new_user` | bool | 新用户标记 |
| `invite_code` | string? | 邀请码 |
| `referrer_id` | string? | 邀请人用户 ID |
| `wx_unionid` | string? | 微信 unionid |
| `member_number` | int? | 展示用会员编号 |
| `like_ids` | array | 点赞的作品业务 ID 列表 |
| `collection_ids` | array | 收藏的模板业务 ID 列表 |
| `last_daily_claim_date` | string? | 每日领豆日期（`YYYY-MM-DD`） |
| `created_at` / `updated_at` | datetime | 时间戳 |

### 3.2 `templates`

与 `Template` 模型一致：含 `pricing_strategy_id`、`tags`、`reference_images`、`status`（`pending`/`approved`/`rejected`）、`is_custom`、`creator_id`、`model_id`、`default_aspect_ratio`、`default_resolution` 等。不再使用文档早期的 `category` / 固定 `price` 字段。

### 3.3 `artworks`

与 `Artwork` 模型一致：含 `user_id`、`user_name`、`user_avatar`、`image_url`、`thumbnail_url`、`artwork_name`、`user_input_prompt`、`aspect_ratio`、`resolution`、`is_release`、`likes_count`、`status`、`tags`、`is_advanced`、`model_id`、`source_task_id`、`task_type`、`comic_data` 等。

### 3.4 `tasks`

异步任务文档字段多于早期简表：含 `progress`、`template_id`、`pricing_strategy_id`、`saved_as_artwork`、`saved_as_template`、`comic_data`、`task_type` 等（见 `generate` 路由写入逻辑）。

### 3.5 `orders`

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | string | 订单号（时间戳 + 随机后缀，唯一） |
| `user_id` | string | 用户 ID |
| `amount_cny` | float | 人民币金额 |
| `beans_amount` | int | 豆子数量 |
| `package_id` | string? | 充值档位 ID |
| `status` | string | `pending` / `paid` / `failed` / `refunded` |
| `platform` | string | `alipay` / `wechat` |
| `transaction_id` | string? | 第三方流水号 |
| `created_at` / `updated_at` | datetime | 时间戳 |

**支付幂等**：跨站回调仅当订单从 `pending` 原子更新为 `paid` 成功后才增加用户余额；无本地订单时插入 `paid` 记录依赖 `id` 唯一索引防止重复入账。

### 3.6 `tickets`

含 `id`（时间戳 + 随机后缀）、`user_id`、`theme`、`content`（消息数组）、`reply_content`、`status`、`created_at`、`updated_at` 等。

### 3.7 其余集合

- **`tags`**：`id`、`label`、`value`、`order`、`created_at`、`updated_at`
- **`pricing_strategies`**：`id`、`name`、`model_id`、`price_1k` / `price_2k` / `price_4k`、时间戳
- **`image_models`**：`id`、`name`、`is_flash`、`supports_512`、`description`、`pricing_strategy_id`、`enabled`、`sort_order`、时间戳
- **`system_settings`**：`key`、`value`、`created_at`、`updated_at`
- **`recharge_packages`**：`id`、`amount_cny`、`beans_amount`、`label`、`sort_order`、`enabled`、时间戳
- **`activation_codes`**：`code`、`used_by_user_id`、`used_at` 等（见激活码路由）
- **`counters`**：`id`（如 `member_number`）、`seq`

---

## 4. 关系说明（概念）

- **User → Artwork**：`artworks.user_id`
- **User → Order**：`orders.user_id`
- **User ↔ Template（收藏）**：`users.collection_ids`
- **User ↔ Artwork（点赞）**：`users.like_ids`
- **Template → Pricing**：`templates.pricing_strategy_id` → `pricing_strategies.id`
- **ImageModel → Pricing**：`image_models.pricing_strategy_id`

MongoDB 无强制外键；删除/一致性由应用层维护。

## 5. 索引（由 `ensure_database_indexes` 创建）

| 集合 | 索引 | 说明 |
| :--- | :--- | :--- |
| `users` | `username` 唯一 | 登录名 |
| `users` | `phone` 唯一 sparse | 有手机号时唯一 |
| `users` | `id` 唯一 | 业务 ID |
| `templates` | `id` 唯一 | |
| `artworks` | `is_release` + `created_at` 降序 | 广场列表 |
| `artworks` | `id` 唯一 | |
| `artworks` | `source_task_id` 唯一 sparse | 一任务对应一作品 |
| `orders` | `id` 唯一 | 防重复订单、回调幂等 |
| `orders` | `user_id` + `created_at` 降序 | 用户订单列表 |
| `tickets` | `user_id` + `updated_at` 降序 | 工单列表 |
| `tickets` | `id` 唯一 | |
| `tasks` | `user_id` + `created_at` 降序 | 任务列表、日配额统计 |
| `tasks` | `id` 唯一 | |
| `activation_codes` | `code` 唯一 | |
| `tags` | `id` 唯一 | |
| `pricing_strategies` | `id` 唯一 | |
| `image_models` | `id` 唯一 | |
| `system_settings` | `key` 唯一 | |
| `counters` | `id` 唯一 | |
| `recharge_packages` | `id` 唯一 | |

若库内已存在违反唯一约束的重复数据，索引创建会失败并打印警告，需先清洗数据。

## 6. 初始化与迁移

- 运行 `python database/init_db.py` 或启动后端（`main.py` 会调用 `init_database()`）会：写入种子数据（若集合为空）、**手机号字段归一**（`migrate_user_phone_single_field`：将遗留的 `phone_number` 并入 `phone` 后删除该字段，并尝试删除旧索引 `uniq_phone_number_sparse`）、**创建/补全索引**。

---

## 7. 安全说明（密码）

当前生产路径使用 **可逆加密**（Fernet）存储 `password_hash`，以便管理端展示需求；这与单向密码哈希（bcrypt/argon2）的安全模型不同。若未来取消「可查看明文」需求，可评估迁移为单向哈希。
