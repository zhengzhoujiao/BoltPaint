# 微信H5支付集成指南

## 快速开始

### 1. 安装依赖

```bash
cd backend
pip install -r requirements.txt
```

### 2. 配置微信支付凭证

#### 获取微信支付凭证

1. 访问 [微信支付商户平台](https://pay.weixin.qq.com/)
2. 登录并进入"账户中心 > API安全"
3. 获取以下信息:
   - **WECHAT_APP_ID**: 微信AppID
   - **WECHAT_MCH_ID**: 商户号
   - **WECHAT_API_KEY**: API密钥（32位字符串）

#### 配置环境变量

编辑 `backend/.env` 文件，添加以下配置:

```env
# 微信支付配置
WECHAT_APP_ID=你的AppID
WECHAT_MCH_ID=你的商户号
WECHAT_API_KEY=你的API密钥
WECHAT_NOTIFY_URL=你的公网回调地址/orders/wechat/notify
```

支付相关环境变量均在 `backend/.env.example` 中，复制为 `.env` 后按需填写即可。

### 3. 启动服务

#### 后端服务

```bash
cd backend
python run.py
```

后端将运行在 `http://localhost:8000`

#### 前端服务

```bash
cd webApp
npm run dev
```

前端将运行在 `http://localhost:5173`

## 支付流程

### 用户支付流程

1. 用户在个人中心点击"充值"
2. 选择充值套餐和支付方式(微信)
3. 点击确认支付
4. 跳转到微信H5支付页面
5. 完成支付后返回结果页面
6. 系统自动查询支付状态并更新余额

### 技术流程

```
前端 -> 创建订单 -> 后端
前端 -> 请求支付URL -> 后端 -> 调用微信API -> 返回支付URL
前端 -> 跳转到微信H5页面
用户 -> 完成支付
微信 -> 异步通知 -> 后端 -> 更新订单状态和用户余额
前端 -> 轮询查询支付状态 -> 后端 -> 查询微信API
前端 -> 显示支付结果
```

## API接口

### 1. 创建支付

**POST** `/orders/{order_id}/wechat/pay`

创建微信H5支付订单，返回支付URL。

**响应示例**:
```json
{
  "success": true,
  "payment_url": "https://wx.tenpay.com/cgi-bin/mmpayweb-bin/checkmweb?...",
  "order_id": "order_1738123456789"
}
```

### 2. 支付回调

**POST** `/orders/wechat/notify`

微信异步通知接口，接收支付结果（XML格式）。

**必须返回**: XML格式的成功响应

### 3. 查询支付状态

**GET** `/orders/{order_id}/wechat/query`

主动查询订单支付状态。

**响应示例**:
```json
{
  "success": true,
  "order_id": "order_1738123456789",
  "trade_state": "SUCCESS",
  "transaction_id": "4200001234567890",
  "is_paid": true
}
```

## 测试说明

### 微信支付测试

> **注意**: 微信支付没有独立的沙箱环境，需要使用真实环境测试。

1. **小额测试**:
   - 建议使用0.01元等小额订单进行测试
   - 测试完成后可以申请退款

2. **内网穿透**（用于回调测试）:

由于微信需要访问公网地址进行回调，本地开发需要使用内网穿透工具:

**使用 ngrok**:
```bash
ngrok http 8000
```

获得公网地址后，更新 `.env`:
```env
WECHAT_NOTIFY_URL=https://your-ngrok-url.ngrok.io/orders/wechat/notify
```

## 生产部署

### 部署前准备

1. **域名配置**:
   - 在微信商户平台配置H5支付域名
   - 确保域名已备案

2. **更新配置**:
   ```env
   WECHAT_NOTIFY_URL=https://your-domain.com/orders/wechat/notify
   ```

3. **IP白名单**:
   - 在商户平台添加服务器IP到白名单

### 安全建议

- ✅ 使用HTTPS协议
- ✅ 妥善保管API密钥，不要提交到代码仓库
- ✅ 验证所有支付回调的签名
- ✅ 实现订单幂等性处理
- ✅ 记录所有支付日志

## 常见问题

### Q: 签名验证失败?

**A**: 检查以下几点:
- API密钥是否正确（32位字符串）
- 签名算法是否正确（MD5或HMAC-SHA256）
- 参数是否按字典序排序

### Q: 回调通知收不到?

**A**: 
- 确认 `WECHAT_NOTIFY_URL` 是公网可访问的地址
- 本地开发使用内网穿透工具
- 检查防火墙设置
- 确保返回正确的XML格式响应

### Q: 支付后余额未更新?

**A**:
- 检查后端日志，确认收到回调通知
- 验证签名是否通过
- 检查订单状态是否正确更新

### Q: H5支付域名配置错误?

**A**:
- 在商户平台"产品中心 > 开发配置"中配置H5支付域名
- 域名必须已备案
- 配置后需要等待审核通过
